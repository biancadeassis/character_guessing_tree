# Character Guessing Game — Binary Search Tree

An interactive character guessing game developed in Java for my Data Structures & Algorithms course at Montana State University. The program uses a binary search tree (BST) to navigate yes/no questions and identify characters.

## Features
- Interactive yes/no character guessing
- Binary search tree implementation with custom node objects
- Breadth-first and inorder tree traversals
- Ability to add new characters and questions
- File-based loading and saving of character data

## Technologies
- Java
- Object-oriented programming
- Binary search trees
- Java collections and file I/O

## Project Files
- `CharacterTree.java` — Tree operations, traversal, game logic, and file handling
- `Node.java` — Node structure and references
- `CharacterTreeDemo.java` — Main program entry point
- `tree.txt` — Character and question data

## Running the Project
1. Download or clone this repository.
2. Open the Java files in Eclipse or another Java development environment.
3. Run `CharacterTreeDemo.java` with `tree.txt` in the project's working directory.
